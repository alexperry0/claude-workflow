# Session Decks

Self-contained HTML slide decks summarizing the learning and experience from individual
Claude Code working sessions. Generated by the [`/session-slides`](../../.claude/commands/session-slides.md)
skill.

## What lives here

Each deck is a single `.html` file named `<YYYY-MM-DD>-<slug>.html`. Decks are:

- **Self-contained** — CSS and JS are inlined; no CDN, no build step, no network needed.
- **Offline-portable** — open the file in any browser, now or years from now.
- **Committed** — versioned with the repo so they're shareable and persist.

## Viewing a deck

Open the `.html` file in a browser. Controls:

| Key | Action |
|-----|--------|
| `→` / `Space` / `PageDown` | Next slide |
| `←` / `PageUp` | Previous slide |
| `Home` / `End` | First / last slide |
| `F` | Toggle fullscreen |
| Click | Right half = next, left half = previous |

The URL hash tracks the current slide, so you can deep-link to a specific one.

## Generating a deck

After a working session, run:

```
/session-slides
```

The skill harvests the session (transcript, archived plan, git diff) with parallel
Opus 4.8 subagents, synthesizes a deck spec, builds the HTML from
`.claude/templates/learning-deck.html`, and runs a fresh-eyes verification pass before
reporting back.
